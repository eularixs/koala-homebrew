# koala-homebrew

> **Note:** Homebrew tap convention requires repo name `homebrew-<name>`.
> This repo is named `koala-homebrew`, which Homebrew won't auto-resolve via
> `brew tap eularixs/koala`. Either rename this repo to `homebrew-koala`, or
> install via direct clone path.

## Install
```
brew tap eularixs/koala https://github.com/eularixs/koala-homebrew.git
brew install --cask eularixs/koala/koala
```
